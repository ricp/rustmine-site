Latest integrated preview · 19 October 2026 UTC

Issue Status progress reached the local preview.

Administrators can set default % Done values for Issue Statuses and choose status-based progress. Checked member Issue lists, details, editors and JSON/XML/CSV show effective progress immediately without changing stored Issue rows. An explicit recalculation saves values by status; an earlier status can remain updated if a later one fails, ready for retry. The exact-head gate passed 459/459 selected checks, followed by private-clone preflight and a guarded local preview switch. Local preview · 19 October 2026

What already works.

These are usable paths in a local Rust build. Each is a bounded part of Redmine, not full parity or a customer-ready installation.

Projects and access

Sign in and manage projects, members, roles, settings, and supported project copies.

Issues and planning

Create and edit issues. Use queries, bulk actions, relations, and watchers, plus Calendar, Gantt, and roadmap views.

Time and reports

Log and review time, use project reports and saved filters, and import supported CSV files.

Team content

Use selected Wiki, Boards, News, Document, and attachment paths. Search and browse project activity.

Code and integrations

Browse selected Git and Subversion repositories and use covered API and webhook paths.

Still unfinished

Complex copy and permission cases, some Wiki, feed, and repository behavior, wider Redmine parity, the finished interface, and release readiness remain.

I have not measured a speed or hosting cost benefit, and this build is not for customer production.
